Firework Coding Lab

Build particle motion and particle generation in p5.js. Five missions. Work through them in order.

THE PROBLEM

Make a firework out of particles

A firework has two stages. A rocket launches from the bottom of the canvas and rises while gravity slows it down. When it stops rising, it explodes into fragments. The fragments fly outward, fall under gravity and fade away. Then the next rocket launches. The animation on the right shows the goal.

Everything you see is a Particle: the rocket is one, and so is every fragment. A particle keeps a position, a velocity and an acceleration, and each frame update(dt) moves it forward by the small time dt that has passed.

The starter code below is a complete program except for two empty pieces. Until you fill them in, nothing moves and nothing explodes. Those two pieces are Missions 1 and 2. Missions 3 to 5 then change the firework further:

  • MISSION 1 Particle.update(dt): make a particle move.
  • MISSION 2 Firework.explode(): generate the fragments.
  • MISSION 3 make the burst a ring.
  • MISSION 4 add wind.
  • MISSION 5 a two-stage firework.

The list of what the starter gives you and the table of functions you will need are at the bottom of this page.

let firework;

function setup() {
  createCanvas(600, 500);
  firework = new Firework();
}

function draw() {
  background(10, 15, 30);
  let dt = Math.min(deltaTime / 1000.0, 0.05);
  firework.update(dt);
  firework.show();
  if (firework.finished()) firework = new Firework();
}

    this.velocity = velocity.copy();
    this.acceleration = createVector(0, 180);

    // TODO 3: update the age
  }

  alive() { return this.age < this.lifetime; }

  show() {
    let opacityValue = 255 * (1 - this.age / this.lifetime);
    opacityValue = constrain(opacityValue, 0, 255);
    noStroke();
    fill(red(this.particleColor), green(this.particleColor),
         blue(this.particleColor), opacityValue);
    circle(this.position.x, this.position.y, this.particleSize);
  }
}

class Firework {
  constructor() {
    this.exploded = false;
    this.fragments = [];
    this.rocket = new Particle(
      createVector(width / 2, height - 10),
      createVector(0, -320), 10, 5, color(255, 230, 120)
    );
  }

  update(dt) {
    if (!this.exploded) {
      this.rocket.update(dt);
      if (this.rocket.velocity.y >= 0) {
        this.explode();
        this.exploded = true;
      }
    } else {
      for (let p of this.fragments) p.update(dt);
      this.fragments = this.fragments.filter(p => p.alive());
    }
  }

    for (let p of this.fragments) p.show();
  }

  finished() {
    return this.exploded && this.fragments.length === 0;

}

MISSION 3

Mission 3 – Make a ring

Keep the direction random. Give every fragment the same initial speed.

You know it works when the burst expands as a circle instead of a filled cloud.

MISSION 4

Mission 4 – Add wind

Accelerate the fragments to the right, without changing their starting positions or velocities. Gravity must keep working.

You know it works when the whole burst drifts to the right as it falls. Remember that every particle has its own acceleration.

MISSION 5

Mission 5 – Two-stage firework

Choose one fragment. Wait 0.7 s after the explosion. Then generate a second burst at that fragment’s current position and remove the fragment that made it. Make the second burst smaller and a different colour.

Your Firework will need to remember three things: which fragment is the source, how much time has passed since the explosion, and whether the second burst has already happened. The show should only restart after the second burst’s fragments have faded.

You know it works when about 0.7 s after the first burst, one spark bursts into a cluster of blue sparks, the original spark is gone, and the next rocket launches only after those have faded.

HOW THE STARTER IS ORGANISED

What is given and what is yours

PieceWhat it does
setup(), draw()Create the 600×500 canvas, compute dt, update and draw the firework, start a new one when it is finished.given
Particle constructorStores position, velocity, acceleration (0, 180), size, age, lifetime and colour.given
Particle.update(dt)Advances one particle by one time step.Mission 1
Particle.alive(), show()A particle is alive while its age is below its lifetime. It is drawn fading out as it ages.given
Firework.update(dt)Updates the rocket; when the rocket’s vertical velocity reaches zero or more, calls explode(). Then updates the fragments and drops the ones that are no longer alive.given
Firework.explode()Creates the fragments.Mission 2

Units: positions are in pixels, velocities in pixels per second, accelerations in pixels per second squared, and dt in seconds. In p5.js, +y points down, so gravity (0, 180) pulls toward the bottom of the canvas.

FUNCTIONS YOU WILL NEED

Your toolbox, in the order you will need it

The examples are small, unrelated snippets that show how each function behaves. They are not the answers.

FunctionWhat it doesTiny exampleWatch out
MISSIONS 1 AND 2 · needed first
a.add(b)Adds vector b into vector a. a changes; b does not.
let a = createVector(1, 2);
a.add(createVector(3, 4));
// a is now (4, 6)
It changes a itself.
p5.Vector.mult(v, s)Returns a new vector equal to v times the number s. v is left alone.
let v = createVector(2, 4);
let w = p5.Vector.mult(v, 0.5);
// w is (1, 2), v is still (2, 4)
Use this when you need “v times s” but must not change v.
dtSeconds since the last frame (given in draw()). A rate times dt is the change over one frame.
// speed 100 px/s, dt = 0.02 s
// moves 100 * 0.02 = 2 px this frame
Forget dt and things jump a whole second of motion every frame.
MISSION 2 · needed next
for (let i = 0; i < n; i++) { … }Repeats the block n times.
for (let i = 0; i < 3; i++) {
  // runs 3 times
}
p5.Vector.random2D()Returns a new vector of length 1 pointing in a random direction.
let d = p5.Vector.random2D();
Length is exactly 1.
random(lo, hi)A random number from lo up to hi.

p.alive()From the starter: true while the particle’s age is below its lifetime.

array.filter(p => test)Returns a new array with only the items for which test is true.

It does not change the old array; assign the result back.
a !== bTrue when a and b are not the same object.

Careful with these pairs. a.add(b) and v.mult(s) change the vector they are called on. p5.Vector.mult(v, s) gives you a new vector and changes nothing. If a vector must keep its value (such as a particle’s acceleration, which is used every frame), do not scale it in place.
